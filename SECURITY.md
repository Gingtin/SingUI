# Security Policy

The SingUI team takes the security and privacy of our users very seriously.

---

## 🔒 Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability in SingUI:

1. **Do NOT open a public issue** on GitHub.
2. Please send an email directly to the maintainer: `gingtincheung@gmail.com` with:
   - A detailed description of the vulnerability.
   - Steps to reproduce or proof-of-concept (PoC).
   - Affected versions and configurations.
3. We will acknowledge receipt of your vulnerability report within 48 hours and work with you on a timely resolution and security advisory release.

Thank you for helping keep SingUI safe and secure for everyone!
